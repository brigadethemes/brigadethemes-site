Brigade Kanban Board – Task Manager & Project Management

Kanban boards for tasks and projects, built into the WordPress dashboard. No external service, no extra logins.

Free · Coming soon to WordPress.org

Features

Drag-and-drop boards

Move tasks between columns as work progresses.

Columns & task cards

Shape each board around your own workflow.

Labels

Colour-coded labels to group and filter tasks.

Board permissions

Control who can view, edit and manage each board, using WordPress capabilities.

REST API

Secure REST endpoints for boards, columns, tasks and labels.

Requirements

WordPress with a modern PHP version. Free and licensed under the GPL.
