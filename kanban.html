Brigade Kanban Board: User Guide

Kanban boards inside WordPress. Every change (dragging a card, saving details, adding a column) is saved instantly, without reloading the page.

Install

  1. Plugins → Add New → Upload Plugin, choose brigade-kanban-board.zip, and activate.
  2. Open Kanban in the admin menu. A first board with three tip cards is ready.
  3. Go to Kanban → Settings and tick the roles that may use the boards. Administrators and Editors can by default.

Boards

  • Boards shows each board with its colour, open and done counts, overdue cards and a progress bar.
  • New board: give it a name, pick a column set and a colour.
Column set Columns
To do · In progress · Done To do, In progress, Done
Software sprint Backlog, To do, In progress, Review, Done
Content calendar Ideas, Writing, Editing, Scheduled, Published
Client projects Leads, Proposal sent, In progress, Waiting on client, Delivered

× on a board deletes it with all its cards (you're asked first). Only the board's creator or an administrator can do this.

Working on a board

  • Add a card: type in "Card title, then Enter" at the bottom of a column. Shift+Enter adds a new line.
  • Move a card: drag it to another column or up and down. Or open it and choose Move to, which works with a keyboard and on phones.
  • Rename the board / change colour: click the name at the top and type, then press Enter. Use the colour square for the colour.
  • Filters: search (titles, descriptions, labels), assignee (or "Unassigned") and priority.

Card details

Click a card to open it:

Field Notes
Title, Description Plain text, with line breaks kept
Assignee Anyone with an allowed role. They get an email (can be turned off).
Due date Red on the card when overdue, amber on the day it's due (not in "done" columns)
Priority Low, Normal, High, Urgent. Normal isn't shown on the card, to keep it clean.
Labels Comma-separated, up to 8
Checklist Type and press Enter. Ticks save immediately. The card shows progress, e.g. 2/3.
Comments Post with the button (or Ctrl/⌘+Enter). The assignee and the card's creator get an email.

Click Save card for the title, description, assignee, date, priority, labels and Move to. The checklist and comments save on their own. Delete card removes the card and its comments.

Each open card has its own address (…&tab=board&board=7&card=23). Share it, and it opens that card.

Columns

Click ⋯ on a column:

  • Rename
  • Card limit: for example 3. The count turns red when the column holds more.
  • Cards here count as done: done cards don't show as overdue and count toward the board's progress. The last column of a new board is already set this way.
  • ← → move the column.
  • Delete column: only empty columns can be deleted.

Add column is at the far right of the board.

My Tasks

Everything assigned to you that isn't done yet, across all boards, sorted by due date and then priority. Click a task to open it on its board.

The My tasks widget on the WordPress dashboard shows your next six (turn it off in Settings).

Settings (administrators only)

  • Who can use the boards: roles. Everyone with these roles sees every board and can be assigned cards.
  • Email alerts: on assignment, on new comments.
  • Dashboard widget
  • Uninstall: tick to delete all boards, cards and settings when the plugin is deleted.

Troubleshooting

Problem Fix
A person isn't in the Assignee list Add their role in Settings.
Emails don't arrive Set up an SMTP plugin. WordPress's default mail is often blocked.
"Move or delete the cards in this column first" Columns with cards can't be deleted, so no work is lost by accident.
Dragging doesn't work on a phone Open the card and use Move to.

For developers

// Only let users with the 'manage_projects' capability use the boards:
add_filter( 'bkb_user_can_use', function ( $allowed, $user ) {
    return user_can( $user, 'manage_projects' );
}, 10, 2 );
